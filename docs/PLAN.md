# Roadmap

## Alpha foundation

- [x] Native activity list, search, inspector, settings, and fictional demo mode.
- [x] Explicit system inventory read with private snapshot cache and short-lived authorization reuse.
- [x] App / developer grouping and exact parent-child service attribution.
- [x] User-agent parking and protected system-daemon tool with recoverable journals.
- [x] Parked-item reconciliation, safe restore conflicts, and recreated-configuration visibility.
- [x] Fixture-based core tests and read-session transport tests.
- [x] Original editable icon, bilingual documentation, contribution and security guides.
- [x] Reproducible packaging scripts and architecture-specific CI / release workflows.

## Before a stable release

- [ ] Complete isolated end-to-end service mutation, reboot, relogin, and recovery validation on each supported platform.
- [ ] Validate inventory projection on older macOS versions and additional system languages.
- [ ] Expand Intel runtime testing beyond CI builds.
- [ ] Review privileged boundaries independently; obtain Developer ID signing and notarization.
- [ ] Add app-configuration recreation diagnostics and explicit recovery export / history cleanup.
- [ ] Localize the app interface beyond Simplified Chinese.

## Out of scope

Disk cleanup, app uninstallation, performance dashboards, user accounts, telemetry, background privilege prompts, installed monitoring daemons, bulk deletion, and private database mutation.
