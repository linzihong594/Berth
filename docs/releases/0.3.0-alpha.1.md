The first public Alpha of **泊 · Berth**, a native macOS background-activity manager.

### Highlights

- Inspect system background activity and its corresponding service configuration.
- Back up and park supported services; restore original files and load state later.
- Keep parked items out of the active list while preserving recovery records.
- Reuse short-lived system authentication for consecutive inventory reads.
- Native settings and a new berth-and-boat icon.

### Downloads

Choose **arm64** for Apple silicon or **x86_64** for Intel. Open the DMG and drag Berth to Applications, or unzip the ZIP. Quit and replace the old app when updating. User and system recovery archives are stored separately and must be retained while services are parked.

Each architecture includes a SHA-256 checksum file. From the download directory, run `shasum -a 256 -c Berth-0.3.0-alpha.1-macos-ARCH.sha256` after replacing ARCH with your architecture.

### Preview limitations

Requires macOS 14+. Binaries are ad-hoc signed, not Developer ID signed or notarized, so macOS may block the first launch. Source builds are available. Read the README before parking a real service; system-record cleanup timing varies, and apps may recreate configurations. Older OS / Intel runtime testing and isolated system-daemon end-to-end coverage remain incomplete. CI build coverage is not a substitute for that testing.
