# Changelog

## 0.3.0-alpha.1 — 2026-11-11

First public Alpha preview.

- Native system background-activity list, search, source inspector, and settings.
- Exact app / developer grouping with local snapshot persistence.
- Reversible parking and restoration of supported user agents and legacy system daemons.
- Completed parked items leave the active list; recreated configurations remain visible.
- Short-lived read authorization reuse, timeout, cancellation, and explicit session close.
- Original berth-and-boat icon with editable artwork source.
- Fictional demo mode, Chinese / English project documentation, MIT license, contribution and security guides.
- Architecture-specific DMG / ZIP packaging, checksums, CI, and release workflows.
- 45 core tests. See docs/VALIDATION.md for tested scope and remaining limitations.

Earlier local development previews were not public releases.
